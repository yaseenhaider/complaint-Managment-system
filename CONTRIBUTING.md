# Contributing

Thanks for contributing to this project.

## Getting Started

1. Fork the repository and create a feature branch.
2. Make focused, minimal changes.
3. Verify the application still works locally.
4. Submit a pull request with a clear description.

## Contribution Guidelines

- Follow existing project structure and naming.
- Keep changes scoped to one concern per PR.
- Update documentation when behavior or setup changes.
- Do not commit secrets or environment-specific files.

## Pull Request Checklist

- [ ] Code and documentation are updated together
- [ ] No unrelated files are changed
- [ ] Changes were tested locally
- [ ] Security-sensitive areas were reviewed
