# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please report it privately to the maintainers instead of opening a public issue.

Include:

- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested remediation (if available)

## Security Practices

- Remove `install.php` after deployment setup
- Rotate default/admin credentials immediately
- Use HTTPS in production
- Restrict database permissions to the minimum required
- Keep PHP, Apache, and MySQL patched
